# SMAP (Social Media Analytics Platform)

> **AI-Driven Social Media Telemetry & Intelligence Platform**

**SMAP** is an advanced, AI-powered social media intelligence dashboard engineered for conversational clarity and multi-dimensional audience telemetry. Transforming raw interactions into actionable insights, SMAP decodes social conversations, tracks audience trajectories, and provides high-fidelity sentiment telemetry.

---

## ⚡ Key Capabilities

- **Real-Time Telemetry HUD**: High-density analytics cockpit tracking views, engagement velocity, and subscriber trajectory.
- **AI Viewership Forecasting**: Multi-horizon predictive modeling contrasting actual telemetry against machine learning forecasts.
- **Sentiment & Neural Cognition**: Deep multi-vector lexical classification separating sentiment distributions (positive, neutral, negative) and nuanced emotional spectrums.
- **Parsed Comment Intelligence**: Live stream ingestion of user commentary categorized by feedback typology (inquiries, constructive remarks, positive signals).
- **Geographic Topology & Activity Heatmaps**: Global audience distribution mapping with automated peak activity window detection.
- **Adaptive Cybernetic Interface**: Precision dark and light modes with fluid responsive layouts and collapsible sidebar navigation.

## 🚀 Getting Started

### Prerequisites

- Node.js (v18+ recommended)
- npm, pnpm, or yarn

### Installation

```bash
# Clone the repository and navigate to the project root
cd smap

# Install dependencies
npm install
```

### Development Server

Launch the Vite local development server:

```bash
npm run dev
```

### Production Build

Compile and bundle production-ready assets:

```bash
npm run build
```

Preview the production build locally:

```bash
npm run preview
```

### Linting

Run Oxlint to check code quality:

```bash
npm run lint
```
